# Aryan Yadav Portfolio

Premium personal portfolio built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site.

## Content

Edit `src/lib/site-data.ts` to update resume, GitHub, LinkedIn, email, and project links. The resume PDF is served from `public/resume/Aryan_Yadav_Software_Engineer.pdf`.

## Deployment

Set `NEXT_PUBLIC_SITE_URL` in Vercel to the final production domain so canonical, robots, and sitemap URLs match the deployed site.
